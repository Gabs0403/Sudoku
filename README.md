# Sudoku Game (Python + Tkinter)

This is a simple **Sudoku game** built using **Python** with a graphical interface powered by **Tkinter**. The application allows users to load a new Sudoku puzzle, input their solution, check if it's correct, and get visual feedback with color-coded entries.

## Features

- Random puzzle loading from a `puzzles/` directory
- Easy-to-use GUI built with Tkinter
- Entry validation with green (correct) or red (incorrect) highlights
- Backend Sudoku solver used to validate player input


## How to Run

1. **Clone the repository** or download the files.

2. Make sure you have **Python 3** installed.

3. Install any required modules (if not already installed). Tkinter usually comes pre-installed with Python.

4. Run the app:

```bash
python gui.py
```
## How to Use

### ✏️ Fill in the Board
- Click on the empty cells.
- Type numbers (1–9) to fill in your solution.

### ✅ Check Your Solution
Click the **"Check"** button to validate your solution:
- **Green cells**: Correct numbers.
- **Red cells**: Incorrect numbers.

### 🔁 Reset / Try a New Game
To start a new puzzle, just click **"New Game"** again.
